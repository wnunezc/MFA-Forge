# MFA-Forge 0.1.21-rc.21

`0.1.21-rc.21` is the local baseline cut to validate the startup launcher-driven update path against the next published RC.

## Scope

- release line: `RC21`
- numeric version: `0.1.21`
- intended MSI asset: `MFA-Forge-RC21-x64.msi`
- publication status: local-only baseline for `RC21 -> RC22`

## Updater change in this line

- the launcher now resolves the latest GitHub prerelease RC instead of assuming only `RC(N+1)`
- the GUI now starts the launcher-driven RC check when the main window opens
- the manual update action remains available, but it now checks for the latest published prerelease RC instead of a hard-coded next RC

## Planned validation

- install local `RC21` on the host as the exact baseline
- publish `RC22` as the next prerelease
- validate `RC21 installed -> open GUI -> launcher discovers RC22 -> checksum verification -> MSI handoff -> installed binaries become 0.1.22`

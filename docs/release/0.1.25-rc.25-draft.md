# MFA-Forge 0.1.25-rc.25

`0.1.25-rc.25` is the local baseline cut after hardening the startup updater with a temporary launcher helper, forced GUI shutdown on real update, and passive MSI execution.

## Scope

- release line: `RC25`
- numeric version: `0.1.25`
- intended MSI asset: `MFA-Forge-RC25-x64.msi`
- publication status: local-only baseline for `RC25 -> RC26`

## Updater correction in this line

- the startup path now passes `--passive`
- the launcher relaunches itself from a helper copy outside the installed bin directory before applying an update
- when a newer RC exists, the launcher closes the GUI process and only then starts `msiexec`

## Planned validation

- install local `RC25` on the host as the exact baseline
- publish `RC26` as the next prerelease
- validate `RC25 installed -> open GUI -> launcher helper -> checksum verification -> passive MSI update -> installed binaries become 0.1.26`
